# Datasets

This directory contains documentation about the datasets
used in my Data Science projects.

## Project 01: Titanic Dataset

### Source
Seaborn Titanic Dataset.

### Description
The dataset contains information about passengers aboard
the Titanic, including demographic information, ticket
class, fare and survival status.

### Main objectives
- Explore passenger characteristics.
- Investigate missing values.
- Analyze survival rates.
- Study relationships between variables.
- Prepare data for future machine learning models.

### Target variable
survived

### Data policy
Raw datasets are not committed to this repository
unless necessary. Dataset sources and acquisition
instructions are documented here.
