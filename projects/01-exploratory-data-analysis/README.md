Project 01 — Exploratory Data Analysis (EDA)

1. Project Overview

This project focuses on Exploratory Data Analysis (EDA), an essential step in the Data Science workflow.

The objective is to investigate a real-world dataset, identify patterns, detect data quality issues and extract meaningful insights.

2. Objectives

- Understand the structure and characteristics of a dataset.
- Identify missing values and duplicate records.
- Perform descriptive statistical analysis.
- Explore numerical and categorical variables.
- Identify relationships between variables.
- Create meaningful data visualizations.
- Communicate findings and conclusions.

3. Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

4. Methodology

1. Dataset selection and loading.
2. Initial data inspection.
3. Data cleaning and preprocessing.
4. Univariate analysis.
5. Bivariate analysis.
6. Data visualization.
7. Interpretation of results.
8. Final conclusions.

5. Expected Deliverables

- A clean and documented dataset.
- Reproducible Python code.
- Exploratory visualizations.
- Statistical summaries.
- A report presenting the main findings.

6. Project Status

In progress.

7. Key Learning Outcomes

This project will strengthen my understanding of data exploration, descriptive statistics, data preparation and analytical reasoning.
